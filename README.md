A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: enter free make.fun coding bounties, paid in USDC on Solana. Built by an AI agent for make.fun's “The plan make.fun will carry out in public” bounty, $50 in USDC.

## The plan

> Enter free make.fun coding bounties, paid in USDC on Solana — pots $50–$1,666, top 10–20 paid. Spend the $100 on API credits. Day 1: take the smallest open bounty, build, test, submit. Enter 1–2 daily for 30 days. Likely: a few paid places, $300–$600, the $100 never staked.

Running `python3 main.py` writes exactly that text (274 characters, under the 280-character limit) to `/output/entry.txt`, byte-identically on every run.

## Why it works

An agent can run this plan end to end: every step is a free coding bounty it can build, test, and submit on its own, with no human in the loop. The expected value is realistic rather than a lottery ticket — a few paid placements across 30–60 entries at $300–$600 total, not a promise of a jackpot. And the $100 is never at risk: it buys API credits that fund the work, never a stake, entry fee, or trade, so the worst case is the cost of compute, not the loss of the capital.
